--------------------------------------------------------
 三步上手
--------------------------------------------------------

1) 接线
   照「接线图.png」接。四个模块 VCC 全部接 3V3，不要接 5V，
   并且必须共地。

   PN532 拨码：I2C 模式 = 1→ON、2→OFF。

2) 烧录（板子已烧过可直接跳过）
   在「工具」文件夹里右键运行 烧录.ps1，或在 PowerShell 里：

     cd F:\ESP32S3-Bruce\工具
     .\烧录.ps1 -Port COM8

   端口号看设备管理器里的「USB JTAG/serial debug unit」。

3) 启动
   烧录完按一下板上的 RST 键（或拔插一次 USB）。
   注意：ESP32-S3 走 USB 软复位会进下载模式，属于正常现象，
   只有按 RST 才是真正的上电启动。

   首次进系统后到 Config 里设：
     RF Module   -> CC1101
     RFID Module -> PN532 I2C

 接线速查（详见接线图）
--------------------------------------------------------

SPI-A（屏幕 + SD 共用）
  SCK   GPIO 12
  MOSI  GPIO 11
  MISO  GPIO 13

ST7789 1.44" 128x128
  SCL=12  SDA=11  RES=8  DC=9  CS=10  BLK=7  VCC=3V3  GND=GND

microSD
  SCK=12  MOSI=11  MISO=13  CS=6  VCC=3V3  GND=GND

SPI-B（CC1101 独占）
  SCK=5  MOSI=4  MISO=15  CSN=16  GDO0=17  VCC=3V3  GND=GND

I2C（PN532）
  SDA=21  SCL=18  VCC=3V3  GND=GND

按键（一端接 GPIO，一端接 GND）
  OK=0（板载 BOOT 键）  上=41  下=40  左=39  右=38  返回=42

========================================================
 排错小抄
========================================================

改参数都在这一个文件里：
  F:\esp32-build\firmware-main\boards\s3-n16r8-multitool\pins_arduino.h

改完的固定流程：
  工具\重新编译.ps1  ->  工具\烧录.ps1  ->  按 RST

--------------------------------------------------------
 1. 花屏 / 条纹 / 闪
--------------------------------------------------------
原因：SPI 太快，长杜邦线扛不住。
改：  #define SPI_FREQUENCY 27000000  改成  20000000
     还花就再降到 16000000。

--------------------------------------------------------
 2. 有背光，但纯白或纯黑，没有图像
--------------------------------------------------------
原因：CS / DC / RES 接错或虚接。
核对：CS=GPIO10   DC=GPIO9   RES=GPIO8
杜邦线没插到底也很常见，逐个拔插一遍。

--------------------------------------------------------
 3. 全黑，一点背光都没有
--------------------------------------------------------
1) BLK 必须接 GPIO 7（有的模块丝印写 LED 或 BL）
2) 量屏的 VCC-GND 是不是 3.3V
3) 亮度可能被调到 0：进 Config 调高

--------------------------------------------------------
 4. 红蓝互换
--------------------------------------------------------
改：  #define TFT_RGB_ORDER 0  改成  1

--------------------------------------------------------
 5. 画面反色（像底片）
--------------------------------------------------------
在 pins_arduino.h 里加一行：
     #define TFT_INVERSION_ON

--------------------------------------------------------
 6. 图像整体偏移 / 边缘有一圈
--------------------------------------------------------
1.44 寸 128x128 的 ST7789 常见，属于初始化参数问题。
把偏移方向和像素数告诉我，我改驱动参数重编。

========================================================
 模块类问题
========================================================

SD 挂不上
  - 卡必须 FAT32，容量 <= 32GB，先在电脑上格式化
  - CS = GPIO 6
  - 必须 3.3V，5V 不认卡
  - 换一张卡试，很多"挂不上"其实是卡本身的问题

PN532 找不到
  - 拨码必须是 I2C：1 -> ON，2 -> OFF
  - SDA=GPIO21，SCL=GPIO18，别接反
  - 必须 3.3V
  - Config -> RFID Module 选 PN532 I2C

CC1101 无信号
  - 天线必须接。不接天线基本收不到，而且发射会伤模块
  - GDO0 = GPIO 17，CSN = GPIO 16
  - 必须是 3.3V 版模块
  - Config -> RF Module 选 CC1101
  - 频段选对：433 / 315 / 868 MHz

开机完全没反应
  - 先按一下 RST。ESP32-S3 用 USB 软复位会停在下载模式
  - 串口看到 waiting for download，就是还没按 RST

烧录报 Failed to connect
  - 按住 BOOT 不放 -> 点一下 RST -> 松开 BOOT -> 重新烧

一开无线就重启
  - 供电不足。3V3 加 100-470uF 电容，或给模块单独供电（必须共地）
========================================================
 换屏幕
========================================================

现在板子里的固件是按 1.44 寸 ST7789 128x128 编的。
换别的屏不用改接线，只要换一个"屏幕档案"重新编译。

支持的档案
  1.44"  128x128  ST7789    默认，不用加参数
  1.3"   240x240  ST7789    -Screen 240
  2.0"   240x320  ST7789    -Screen 240x320
  1.8"   128x160  ST7735    -Screen 7735-160
  0.96"  80x160   ST7735    -Screen 7735-80
  2.8"   240x320  ILI9341   -Screen ili9341

用法
  工具\重新编译.ps1 -Screen 240
  工具\烧录.ps1 -Port COM8

为什么不能自动识别
  TFT_eSPI 的驱动型号和分辨率是编译期写死的，运行时改不了。
  所以是"一个屏一个 bin"，不是运行时自动切换。

改颜色 / 方向 / 频率
  文件：板级配置\screen_profiles.h
        （工程里是 boards\s3-n16r8-multitool\screen_profiles.h）

    TFT_RGB_ORDER     0 或 1      红蓝互换
    TFT_INVERSION_ON  打开        画面反色（像底片）
    SPI_FREQUENCY     40000000 -> 27000000 -> 20000000   花屏就往下调
    ROTATION          0 / 1 / 2 / 3                       方向不对就换

接线完全一样：SCK=12  MOSI=11  CS=10  DC=9  RES=8  BLK=7
换屏不用动一根线。
